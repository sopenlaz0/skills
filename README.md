# skills

A collection of agent skills. Each skill is a folder containing a `SKILL.md`.

## Skills

| Skill | What it does |
| --- | --- |
| [performance-optimization-loop](performance-optimization-loop/SKILL.md) | Slow app or performance sprint: measure user journeys, optimize verified bottlenecks, and preserve proven gains. |

## Install

Copy a skill's folder into your agent's skills directory, so that it ends up at `<skills-dir>/<skill-name>/SKILL.md`.
